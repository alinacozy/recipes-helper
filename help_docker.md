`docker image ls` - посмотреть все образы, которые есть

`docker build .` - собрать образ из докерфайла

`docker run -dit -p 5432:5432 <первые 4 цифры id образа>` - запустить контейнер с бд

# Как запустить контейнер с нашим приложением с помощью docker compose

### 1. В терминале переходим в папку проекта
```
cd /путь/к/нашему/проекту
```
В моем случае: `cd recipes-helper`

### 2. Собираем jar-файл приложения
```
mvn clean package -DskipTests
```
Используем -DskipTests, так как у нас нет тестов.
После этого в папке target появится наш jar-файл.

### 3. Запускаем сборку и запуск контейнеров через Docker Compose
```
docker compose up --build
```
Ключ --build гарантирует, что образы пересоберутся, если были изменения.
Docker автоматически поднимет сервисы, описанные в docker-compose.yml (Spring Boot и Postgres).
Можно в конце команды добавить -d, что запустит контейнер в фоновом режиме.
Если у нас docker compose версии ниже, чем 2.Х, используем `docker-compose up --build`

### Как остановить контейнеры?

Для остановки всех сервисов нажмите Ctrl+C в терминале, где работает Docker Compose.

Чтобы полностью удалить контейнеры, выполните: `docker compose down`или то же самое через черточку для старых версий
